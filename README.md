# 枫桥夜泊

一段 84 秒的原生字符画：张继《枫桥夜泊》的那一夜——月落、乌啼、霜满天，江枫渔火，夜半钟声，然后天亮。画面是 312 × 64 格的字符，每一帧按规则生成，没有一张图片；配乐选自署名许可（CC BY）的作品。

在线看：https://toby-bridges.github.io/fengqiao/ （有声音，点一下开始；手机请横屏）

这个仓库只放构建产物（单个 `index.html`），源码暂未公开。
